A construction schedule you can check by hand.

Multi-calendar CPM with all four relationship types and all ten constraint types. DCMA 14-point quality assessment where a check that could not run says skipped, not passed. Primavera XER and MS Project interchange that keeps the logic. Monte Carlo risk, resource levelling, and delay attribution that sums.

See it work

An eight-storey mid-rise fragment on two calendars, with a lag, a procurement constraint and a Christmas shutdown — scheduled and scored.

Import your own

A Primavera .xer or an MS Project .xml. The import report tells you how much logic came across — because a network with none reads as 100% critical and looks fine.

What it refuses to do

  • Clamp negative float. It is the output. It is the reason the planner set the constraint.
  • Default silently. Every coercion, drop and fallback emits an issue with a stable code and the action taken.
  • Score a schedule 14/14 for data it never had. Checks needing a baseline, actuals or resources report as skipped and leave the denominator.
  • Return numbers computed over a broken network. Circular logic names the loop and produces no dates.
  • Move a contract date nobody approved. Levelling within float reports what it could not resolve rather than extending the finish.
