A Primavera .xer or a Microsoft Project .xml (MSPDI) export. Nothing is stored — the file is read, scheduled and rendered in the response.

What comes across

  • Relationships, with their type and lag — the TASKPRED table. An import that omits it produces a network with no critical path, where every activity reads as critical with zero float.
  • Calendars, including exceptions. An unparsed Christmas shutdown moves every downstream date two weeks early.
  • Constraints, actual dates and remaining duration, so a progressed schedule reschedules from its data date.
  • Costs from TASKRSRC and notes from TASKMEMO — neither lives on TASK, and reading them from there yields zero.

What does not

Binary .mpp is a proprietary, undocumented format. Export as XML from Microsoft Project instead; it round-trips losslessly. Primavera PMXML is read, but by a path that does not carry relationships — export .xer for a full import.
